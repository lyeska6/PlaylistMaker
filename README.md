# Playlist maker

Android-приложение для поиска треков и создания персональных плейлистов.

### В приложении есть такие функции как:
- прослушивание кусочка трека,
- добавление и удаление избранных треков,
- добавление и изменение плейлистов,
- настройка обложки, названия и описания плейлистов
- и изменение темы приложения между темной и светлой.

На этом проекте я в течение года оттачивала все возможные навыки программирования мобильных приложений. Углублялась в язык и различные библиотеки.

**Стек:** Kotlin, Fragment, Coroutines, Room, Koin, SQLite, Retrofit, Glide, Live Data, MVVM, Android SDK, Git
